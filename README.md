# The-ment4ls-Backstory
A repository that outlines all the steps ment4ls took in his tech career, from his first day learning how to code to the day he becomes a senior in whatever path of Tech he decided to commit to. A Tech Diary, basically.
## How you should approach this repo
Think of this as an ongoing, written novel with new arcs coming out every so often. I will make sure my posts are informative, however I'll flex my minor story-writing skills to make it an enjoyable read as well. That way, it'll be easier for others to learn what I learned as they read through it because it'll be such an interesting read.
