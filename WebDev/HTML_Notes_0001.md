# What I remember about basic and semantic html
For a good two months now, I've been working on the Responsive Web Development course on freecodecamp. It's been a bit of a struggle to sneak it in whilst having to study my other university modules, but that's nothing a little time management couldn't fix. In any case, here are a few things to note about semantic and basic html when you're going through the course:

## It is a lot to remember, so make it easier on yourself and note things down
In my first year of programming, I have come to realize that knowing every minute piece of syntax is impossible, however it is still good to have an idea of what everything you're learning about is doing. Semantic html is no different. There are a lot elements to play with and each one has a different purpose, even if they visually do the same thing. That is why noting them down somewhere and sticking short descriptions of each tag is important. Some are intuitively easy to remember, like heading tags or the paragraph tag, as you will use them often enough to have them be muscle memory. I will not be logging those in this readme. I want to focus on the tags with nuance and those that I hardly get the chance to use in my current stage (as I hardly code outside of school), but are still very important to creating a professional website. 
Does AI know how to do all of this and more? I assume so, but I won't let AI stop me from feeding my hunger for learning and neither should you!

## The tag dictionary
section - this tag is a bit self-explanatory, it separates your body content into sections. Get into the habit of using this one, as it will be very helpful in grouping your content for CSS components.
